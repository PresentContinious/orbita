```
Проект ОРБИТА — zero-player космическая песочница (React + Vite, canvas 2D, весь код и UI по-русски):
боты-государства колонизируют планеты, добывают руду, торгуют, воюют и мирятся сами; игрок наблюдает
и вмешивается «инструментами бога». Работаем в этой папке, ветка feature/foundation.

СНАЧАЛА ПРОЧИТАЙ (именно в этом порядке, до любых правок):
1. docs/MECHANICS.md — справочник ВСЕХ игровых механик с балансными цифрами. Это карта проекта.
   Когда меняешь баланс — обновляй этот файл вместе с кодом.
2. src/solar/civ/constants.js — классы кораблей (SHIP), CAP_KINDS, цены, пороги войны/союза.
3. src/solar/civ/index.js (~2000 строк, главный) — класс Civ: всё состояние (states, ships, wars,
   rel, incidents, truce…), решения ботов (_stateDecide → _warDecide/economy), весь жизненный цикл
   кораблей (_ships — миссии siege/blockade/raid/guard/invade/reinforce/sabotage/hunt/trade/mine/
   colonize/outpost/pirateMove), наземные войны (_groundWars), перехват конвоев, ПВО (_pvoIntercept),
   пираты (_pirateDecide), отрисовка кораблей/зон/маркеров (drawUnder/drawOver), справки для UI
   (summary/missionText).
4. src/solar/civ/diplomacy.js — причинная дипломатия: relCauses, declareWar (с поводом и intelA/B —
   туман войны), makePeace (счёт войны → уступка планеты/контрибуция), перемирия, drift.
5. src/solar/civ/economy.js — население, недовольство колоний (p.unrest → сецессии), добыча руды,
   мобилизация по шумной оценке угрозы, караваны, колонизация, аванпосты, верфи (таймеры), откуп пиратам.
6. src/solar/engine.js — физика/рендер. КЛЮЧЕВОЕ: фиксированный тик логики (CIV_TICK=0.05, аккумулятор
   civAcc в _update) — поведение игры обязано не зависеть от FPS и скорости ×1/×2/×5/×10; отрисовка
   кораблей интерполируется между тиками (px/py + civAcc/civTickSize).
7. src/solar/gen.js (генерация карты, недра oreRes), src/App.jsx (HUD: дипломатия, лента с flyTo,
   карточка планеты), src/solar/sprites.js + src/assets/sprites/*.svg (перекраска через --accent).

АРХИТЕКТУРНЫЕ ПРАВИЛА:
- Всё состояние живёт в Civ; модули diplomacy/economy экспортируют функции fn(civ, ...), класс держит
  тонкие методы-делегаты со старыми именами — вызовы не ломать.
- Любые вероятности в логике — только вида Math.random() < x * h (h — тик), иначе сломается
  независимость от скорости.
- Лог событий: this.log(текст, { x, y, imp }) — координаты делают событие кликабельным (перелёт камеры),
  imp — янтарная подсветка.
- Разбивку index.js на новые модули НЕ продолжать без явной просьбы.

КАК РАБОТАТЬ СО МНОЙ:
- Без сабагентов. Без вопросов-согласований по мелочи — делай реальные изменения сразу.
- Коммиты редкие, крупными осмысленными порциями, сообщения по-русски, БЕЗ Co-Authored-By.
  НИКОГДА не пушить.
- Проверка: npx vite build (должно быть ✓), дев-сервер: npm run dev → localhost:5173.

СТАТУС: сделаны фундамент (фикс-тик, скорости), причинная дипломатия со счётом войны и миром
с условиями, руда+аванпосты+зоны с инцидентами, война 2.0 (мобилизация, классы кораблей, верфи,
наземный десант, перехват конвоев, гибридная война, наёмники, туман войны), недовольство колоний,
маркеры войны на карте. ОДОБРЕНО И ЖДЁТ: Батч C — пираты (контрабанда в блокады, тайные контракты
со скандалом при вскрытии, пиратский король); Батч D — договоры/вассалы/лига против гегемона,
характеры-архетипы ботов (агрессивный/умный/тупой; «лейтенант-ветеран»; «робототехник» с дронами-
камикадзе), лидеры/перевороты, события-кризисы, хроника эпохи. Дальняя цель — несколько звёздных систем.

Задача: проанализируй всё перечисленное, собери полную картину и подтверди готовность короткой
```
