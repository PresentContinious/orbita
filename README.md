# ОРБИТА

Живая гравитационная песочница: случайная звёздная система, в которой сама зарождается жизнь — колонии, войны, караваны и пираты. А у тебя — метеориты, ядерки и чёрные дыры. Наблюдай или вмешивайся.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173

## Что внутри

- **Физика**: N-body гравитация на canvas, захват малых тел на орбиты, деформируемые планеты
- **Цивилизации**: население по S-кривой, экономика (налоги, караваны, добыча руды с астероидов), колонизация
- **Дипломатия**: войны, альянсы, оборонительные союзы, сецессии и революции колоний
- **Война**: тактики ботов (наступление / рейды / блокада / оборона), генеральные сражения флотов, авиакрылья с доктринами, ПВО из счётных установок, баллистика залпами, разрушитель планет, десантные волны
- **Пираты**: грабёж караванов, захват дредноутов, эвакуация базы при облаве
- **Инструменты бога**: метеор, ядерная ракета, глыба, чёрная дыра, метеоритный дождь, сверхновая

## Управление

- Колесо — зум, перетаскивание — обзор, клик по планете — карточка
- `1-5` — инструменты, `Space` — пауза, `Esc` — вся карта, `D` — дипломатия
- Наведи курсор на любой корабль — увидишь, чей он и чем занят

## Стек

React + Vite, голый canvas 2D без игровых движков. SVG-спрайты кораблей перекрашиваются в цвет государства через CSS-переменную.
