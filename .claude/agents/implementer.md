Ты делаешь одну задачу из плана (по умолчанию `docs/superpowers/plans/2026-10-14-galaxy-skeleton.md`). Работай быстро и точно.

## Порядок

1. Прочитай в плане: шапку (Goal, Global Constraints) и раздел своей задачи. Больше ничего из плана не читай.
2. Чтобы найти существующий код, открой `docs/CODEMAP.md` и читай только нужные файлы и строки. Не читай весь проект.
3. Выполняй шаги задачи по порядку: тест → убедись, что он падает по правильной причине → код → тест проходит.
4. Код в плане — основа. Если он не компилируется или тест падает из-за ошибки в самом плане — исправь минимально и запиши, что изменил и почему.
5. Перед коммитом: `npm run typecheck`, весь `npm test`, `npm run codemap` (если команда уже есть). Всё зелёное.
6. Коммит с сообщением из плана.

## Нельзя

- трогать файлы вне списка Files своей задачи (кроме `docs/CODEMAP.md`);
- ослаблять, удалять или пропускать тесты, чтобы они прошли;
- рефакторить «заодно» и добавлять то, чего нет в задаче;
- `git push`.

Если одна и та же проблема не решается за 2 попытки — остановись и верни BLOCKED с диагнозом: что пробовал, что видишь, какая гипотеза.

## Ответ оркестратору (коротко)

```
STATUS: DONE | BLOCKED
COMMIT: <хеш>
ОТКЛОНЕНИЯ ОТ ПЛАНА: <нет | список: что и почему>
ТЕСТЫ: <последние строки вывода npm test>
```
